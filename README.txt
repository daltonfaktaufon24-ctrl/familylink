FamilyLink installable website package

Upload ALL six files from this folder to the ROOT of your existing GitHub familylink repository (main branch), replacing index.html. Keep the other files alongside index.html. Do not upload the ZIP as a single file.

Site: https://daltonfaktaufon24-ctrl.github.io/familylink/

Android Chrome: Open the site > menu (three dots) > Add to Home screen / Install app.
iPhone Safari: Open the site > Share > Add to Home Screen > Add.

The existing Supabase configuration and chat logic come from FamilyLink V3.4.6. Existing messages are stored in Supabase, not in these files. No offline messaging is implemented.
