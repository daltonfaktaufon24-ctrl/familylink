FamilyLink V3.3 — Audited private-file edition

Share the HTML file itself with your wife. Do not send a ChatGPT sandbox link.

1. On iPhone, save HTML to Files. Open in Edge or Safari if the browser supports local HTML files.
2. Stay connected to the internet.
3. Create a separate account with her own email, confirm email if required.
4. Save display name and choose JOIN FAMILY, not Create Family.
5. Enter the full code generated by your existing family account (expires in 24 hours; single use).
6. Test by sending a message in both directions.

Important limitations:
- iOS browsers may block network fetch requests from local HTML (file/external-file origin). If the connection fails, a file-only approach may need a native app wrapper or browser-specific workaround. This is not fixable solely by removing the Supabase library.
- Messages are NOT end-to-end encrypted; Supabase database access policies must be audited.
- HTML files can be copied. File possession alone does not restrict access; authentication and invitation membership are the actual access controls.
- Voice/video calling is a demo only.
- The app has not been live-tested on your wife's iPhone or against the live Supabase project.
- Keep the Supabase service-role/secret key out of the HTML.
